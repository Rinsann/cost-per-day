# Cost Per Day App UI Design Brief

## 设计参考来源

本目录中的图片来自 Figma 生成的深色记账 App 设计稿。

这些图片只作为 UI 风格和交互参考，不代表要一次性重做整个 App。

主设计来源以 Figma 生成的深色记账 App 版本为主参考，不采用 UXPilot 和 Uizard 版本。

## 视觉方向

- 深色背景：接近 #08080F
- 主色：薄荷绿色，接近 #3DD9AC
- 支出警示色：珊瑚红，接近 #FF6B6B
- 卡片背景：深紫黑 / 深灰
- 金额数字使用更醒目的等宽或粗体风格
- 整体风格：深色、圆角、卡片化、移动端优先

## 当前产品结构

底部 Tab：

1. 记账
2. 统计
3. 成本
4. 我的

中间 + 按钮用于打开快速记账弹层。

## 重要说明

03-budget-analysis-reference-not-current-cost-page.png 不是当前 App 原有的成本分析页面。

当前 App 原有的成本分析功能必须保留，功能包括：

- 长期消费品真实日均成本
- 目标日均成本
- 还需使用天数
- 预计达成日期
- 是否应该换新

不要用 Figma 的预算追踪页面替换现有成本分析页面。

## 当前优先实现

下一小版本只实现：

- 点击底部中间 + 按钮
- 打开快速记账 Bottom Sheet
- 支持支出 / 收入切换
- 支持金额输入
- 支持分类选择
- 支持备注
- 支持自定义数字键盘
- 支持保存到 AsyncStorage
- 保存后刷新记账首页最近记录

## 暂不实现

- 不做完整统计图表
- 不做真实登录
- 不做云同步
- 不重做成本分析页面
- 不修改 Product 数据结构

## 二级/三级页面 UI 规则

- 所有详情页、编辑页、设置页、统计明细页都必须延续深色 UI。
- 页面标题、返回按钮、卡片、文字颜色、间距必须和主 Tab 页面一致。
- 禁止出现白底卡片 + 浅色文字。
- 安卓返回手势不能出现明显闪白。
- 新页面上线前必须真机检查：SafeArea、底部导航遮挡、返回手势、文字可读性。
